# Compai

LAAGAM's company knowledge and business systems, connected for people and AI agents.

Compai shares how we build that system: the memory it keeps, the tools agents can use, and the checks before work is considered finished. Company data and private applications are not included.

- [Explore projects](https://usecompai.com/projects.html)
- [Documentation](https://usecompai.com/playbook/)
- [Architecture](chapters/03-architecture.md)
- [Starter kit](kit/README.md)
- [Skills](skills/CATALOG.md)

The v6.3 starter code is a reference implementation, not a universal installer or a public copy of the private runtime. Configure and test it for your sources, identities and approval rules. Sample data and policy values are illustrative, not company results or recommended operating thresholds.

## November update

[The release notes](chapters/37-november-update.md) cover customer care, parcel tracking, hiring, the people portal, creative work and safer execution. Each method distinguishes what was tested from what people are using and what still needs review.

The kit adds [executable workflow checks](kit/patterns/checked-work/README.md): stale sources, revoked access, uncertain retries and the steps before an employee handoff is complete. These are small examples to adapt, not the private applications.

The manifest describes package contents, not company telemetry.
