# Compai

Tools, code and working notes from inside LAAGAM.

Compai shares the architecture behind a company brain: memory, AI agents, controlled connections and checked outcomes. Company data and private applications are not included.

- [Explore projects](https://usecompai.com/projects.html)
- [Documentation](https://usecompai.com/playbook/)
- [Architecture](chapters/03-architecture.md)
- [Starter kit](kit/README.md)
- [Skills](skills/CATALOG.md)

The v6.2 starter code is a reference implementation, not a universal installer or a public copy of the private runtime. Configure and test it for your sources, identities and approval rules. Sample data and policy values are illustrative, not company results or recommended operating thresholds.

This editorial edition removes company figures and consolidates reading paths. The manifest describes package contents, not company telemetry.
