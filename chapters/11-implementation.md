# Start with one useful job

Choose a problem with an owner and a result that can be checked in a source system.

Map the job, sources, access and approval rules. Build a read-only version with a fictional fixture. Connect a limited real source under the intended identity. Add preparation and review before writes.

Run failure cases, check the destination and document rollback. The process owner should review the result before widening access.

Use the [starter kit](../kit/README.md), [architecture](03-architecture.md) and [capability contract](25-capability-registry.md). Adapt them to your systems; they are not a universal installer.
