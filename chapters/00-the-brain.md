# Company memory

Company memory keeps decisions, reasoning, project context, reusable procedures and previous results. It is not a replica of every operational database.

Give each durable record a stable identifier, owner, audience, source references, status and review date. Put the current conclusion first and link the history beneath it.

Separate testimony from checked facts. A meeting can explain a campaign decision; its sales figure still needs the sales system. Preserve unresolved disagreements.

Retrieve within the caller's scope. Return sources and freshness with the content. If evidence is missing, say so and consult the source where possible.

Test the same query with different roles. Test correction and deletion: an obsolete answer must stop winning, and a removed private record must not survive in a cache or index.
