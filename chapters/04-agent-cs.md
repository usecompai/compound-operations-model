# Customer care drafts

Read the request, current order state and applicable policy. Use memory for tone and precedent, but the order source for current facts.

Draft a response with evidence and identify any required action. Refunds, replacements and exceptions follow approved company rules, not thresholds invented by the model.

A language check is not permission to send. Verify identity, destination, policy and authority separately. Store approved corrections for future work.

Test ambiguous orders, stale tracking, exceptions, duplicate requests and unauthorised refunds. Starter code is a reference; a real helpdesk connection needs end-to-end verification.
