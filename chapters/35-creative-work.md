# Creative work

Turn selected source clips into an edit the team can review, with captions, versions and the instructions needed to reproduce it.

## Keep the source

Video files stay in the media archive. Company memory holds the brief, usage constraints, approved references and links to those files. A working copy is not a new source of truth.

## Prepare the edit

The agent combines the brief with editing, captioning and quality-checking methods. It can prepare cuts, motion text, caption timing and exports for different formats. Each output keeps its source files and edit settings.

Technical checks cover duration, dimensions, audio and missing media. A person still watches the result, listens to it and checks the captions before publication.

## Learn without inventing results

Where creative assets can be matched to paid or organic reporting, the team can compare them and write the next brief. A promising pattern is a hypothesis for the next test, not proof that an edit caused better performance.

## What we checked

The editing stack passed render checks in the intended workspaces. A real source-clip edit and export variants were produced. This does not establish routine team adoption, automatic publication or campaign uplift. Transcription and creative approval still need review.
