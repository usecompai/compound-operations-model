# The company operating layer

Compai connects shared context with controlled ways to work in company systems. A focused dashboard, document workflow and AI agent can use the same contracts.

Start with the work surface: what does someone need to see or finish? Then choose its sources, memory and capabilities. The job should decide the interface.

The company keeps its context and connections. Models remain interchangeable. The permission layer defines what can be read, prepared or changed. The interface shows what was checked and where a person decides.

Build a read-only view first. Add a draft workflow when useful. Allow approved writes only after verification and rollback have been tested with the process owner.
