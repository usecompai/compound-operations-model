# Give work the right context

A context pack contains the evidence needed for a particular job, not the entire company archive.

## Inputs

Caller identity, project, requested outcome, permitted tools and required sources.

Resolve the owner and current decisions. Retrieve relevant memory within the caller's audience. Read live systems for volatile facts. Attach references, retrieval time and source limitations.

Return an explicit state: ready, incomplete, stale, conflicting or permission-blocked. Missing evidence must affect the next action. Never turn an inaccessible record into an empty result that appears complete.

## Verification

Test conflicting documents, a stale figure and an inaccessible record. Check that each issue is reported without exposing private content or silently reusing stale values. Keep the pack identifier with the outcome.
