# Store traffic and media

Use when investigating whether media activity and store demand move together. Read authorised traffic, POS sales, geographic ad spend and web sessions. Match timezone, location and reporting window. Report source coverage and confounders. Correlation, lag and an attribution model are not proof of incrementality. Propose a controlled test when the decision warrants one. Keep customer-level data private. Return sources, method, uncertainty and next check. No budget changes or store-opening decisions are authorised by this skill.

## Verification

Test with fictional records, a missing source and an unauthorised action. Keep the evidence, failures and human decision separate.
