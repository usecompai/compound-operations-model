# Omnichannel growth review

Use when comparing online, physical retail and wholesale performance. Read the approved sales, traffic, advertising and lifecycle sources over compatible windows. Separate observed correlation from a causal claim. Account for promotions, availability, weather and changes in channel coverage. Produce a sourced comparison, unresolved questions and a bounded proposal with an owner. Do not move budget or send messages without approval. Verify the input definitions and missing data before proposing an experiment. Set success criteria and a stop condition from the company's own policy, not this template.

## Verification

Test with fictional records, a missing source and an unauthorised action. Keep the evidence, failures and human decision separate.
